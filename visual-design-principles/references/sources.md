## Applying advice across media

*The New Basics* includes exploratory graphic exercises; *Refactoring UI* offers practical interface techniques. Their different purposes matter. Wide formal exploration can help an expressive composition, while an existing interface may need a narrow change. A grid can unify varied work without forcing every UI element into a percentage width. Depth can be communicated by position, overlap, value, borders, or shadows according to the chosen system. Neither source creates a universal obligation to use a particular visual treatment.

Treat these reconciliations as this skill's synthesis, not a joint statement by the authors. Keep source claims, adaptations, and observed outcomes distinguishable.
