# ibm-design changelog

## 1.0.0 — 2026-10-10
First release, built with the user's decisions (see SKILL.md → Decisions) and hardened by:
- **Smoke tests** (4 fresh agents: settings UI, Chinese phone long image, 6-slide deck, code-video frames). ~80 findings fixed: kit components (modal, danger buttons, checkbox/radio/toggle, select chevron, side nav, collapsible header, page header, snippet, stacking table, slide kit, full grid helpers), CJK typography (punctuation routing, line-start trimming, locale stacks, 95% rule), chunked/stitched tall renders, `--slides`/state capture/PDF page check, alias-aware icon search with `--px/--color/--inner`, tested Canvas setup for video, consistent slide sizes and per-medium audit runs.
- **GPT-6 Astra review** (13 findings, all addressed): per-variant `:active` button states; audit now checks SVG-painted backgrounds, rendered SVG text size, focus by element identity vs unfocused baseline, locale-correct CJK faces, `<use>` icons and inner glyphs, and reports unverifiable text; Carbon-exact fluid type interpolation; `--lite` covers zones and all categorical groups; charts drawn at container width so exports never clip; invalid fields keep a distinct focus ring; dark warning glyph in all themes; specimen type scale fixed; scaffold refuses to overwrite and can bundle fonts; toggle doc corrected (Carbon's "on" = support-success); offline claims made precise.

- **GPT-6 Astra confirmation passes** (rounds 2–5): ghost pressed state reworked to ≥4.95:1 on every theme/layer; audit handles SVG gradients (unverified), propagates unknown backgrounds, uses full rendered transforms (getScreenCTM), requires focus outlines to differ from the unfocused baseline, resolves only local `<use>` refs (external → unverified); locale stacks moved into `--cds-font-*` variables with a zero-specificity lang-root rule (code/pre/quotes keep their roles in zh/zh-TW/ja/ko); scaffold preflights every destination; `--fonts` bundles all weights/italics of Sans, Serif, Mono and Sans Condensed (64 faces). Final verdict: **ship v1.0.0**.
- **Kept deliberately** (flagged for the user): a toggle that is *on* uses Carbon's `support-success` green rather than interaction blue — Carbon fidelity over the strict "blue owns interaction" reading.
